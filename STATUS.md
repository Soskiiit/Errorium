# STATUS.md — Текущее состояние и следующий шаг проекта Errorium

## 1. Текущий статус проекта
- **Этап:** КТ 1 (Архитектурное проектирование, спецификации, Protobuf-контракты).
- **Готовность документации:** Полная структура `docs/` (Product, Tech, Service, Manifest) развернута согласно методологии SDD НИРС 2026.
- **Интерфейсные контракты:** Описаны `protos/search.proto` и `protos/graph.proto`.
- **Новые функциональные направления:**
  - Интерактивный граф связанных тредов (дубликаты, ссылки в ответах) на странице поиска.
  - Модуль аутентификации и авторизации (SSO через OAuth2/OIDC, JWT, RBAC).
  - Панель администратора (Admin Dashboard) для управления индексами, промптами RAG и мониторинга.

## 2. Матрица готовности сервисов

| Компонент | Роль | Статус | Ближайшая задача |
| :--- | :--- | :--- | :--- |
| **Search Engine Indexer** | Роль 1 | Каркас готов | Реализация потокового парсера XML дампа и токенизатора |
| **Search Engine Core** | Роль 2 | Специфицирован (gRPC) | Реализация чтения инвертированного индекса и BM25 с нуля |
| **Gateway & MCP Service** | Роль 3 | Специфицирован (REST/MCP/Proto) | Реализация gRPC клиента, SSO/Auth |
| **Web Frontend** | Роль 4 | Каркас готов | Разработка UI поиска, визуализатора графа знаний и админки |
