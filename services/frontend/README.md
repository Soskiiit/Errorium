# Web Frontend

> **Роль 4: Frontend & Data Visualization Engineer**  
> Пользовательский веб-интерфейс, визуализация интерактивного графа связанных тредов Stack Overflow и панель администратора.

---

## 1. Назначение и зона ответственности

Сервис реализует современный Single Page Application (SPA) веб-интерфейс без сторонних JS-фреймворков (Pure Vanilla JS / HTML5 / CSS3), строго соответствующий утвержденной дизайн-системе (`references/Chat-screen.png` и `references/Chat-screen-menu-not-authorized.png`):
- **Hero-экран поиска:** центрированный парящий маскот, фирменные слоганы в моноширинном начертании (`Element 404. Reacts with developers` / `Stack overflow. Issue overknown.`), синяя световая аура и нижний эллиптический спотлайт.
- **Интерактивный Prompt Bar:** капсульный темный контейнер со стеклянным эффектом, кнопкой быстрых пресетов `+`, автоувеличением высоты ввода, синей круглой кнопкой отправки `↑` и предупреждением `AI can make mistakes`.
- **Выдвижная навигация (Drawer):** полнофункциональное боковое меню со строкой поиска, списком недавних чатов (`Recent chats`), кнопками `MCP`, `About us`, плавающей белой пилюлей `New chat`, авторизацией и настройками.
- **RAG & SERP выдача:** динамический вывод карточки синтезированного решения, блоков кода с кнопкой копирования и ранжированных источников Stack Overflow.
- **Модальные окна:** интеграция MCP с выдачей Bearer-токена и готового конфига JSON для Cursor / Claude Code, окно About us, SSO-авторизация и настройки.

### Основные задачи:
1. **Экран поиска и SERP (`/` и `/search`):**
   - Удобное поле ввода с поддержкой многострочных стектрейсов и кода.
   - Фильтры по технологиям и языкам (Java, Python, Go, C++, TypeScript).
   - Вывод списка результатов BM25 с рейтингом голосов и тегами.
2. **Панель RAG-ответа:**
   - Отображение структурированного ответа от LLM в реальном времени через Server-Sent Events (SSE).
   - Подсветка синтаксиса блоков кода с кнопкой быстрого копирования.
   - Раскрываемый список оригинальных источников Stack Overflow.
3. **Интерактивный граф SO-тредов:**
   - Отрисовка подграфа связанных обсуждений на Canvas / SVG (D3.js / React Flow / Cytoscape).
   - Цветовая дифференциация узлов:
     - 🟢 **Зеленый:** наиболее релевантный тред (Top-1 BM25).
     - 🟡 **Желтый:** остальные результаты выдачи (Top-K).
     - 🔵 **Синий:** треды-дубликаты (`DUPLICATE_OF`).
     - 🟣 **Фиолетовый:** обсуждения, на которые ссылаются в ответах (`LINKED_IN_ANSWER`).
   - Интерактивность:
     - *Hover:* всплывающая подсказка с заголовком, сниппетом и иконкой наличия принятого ответа (✅).
     - *Click:* открытие модального окна или панели с детальным текстом принятого ответа (`GetThreadDetails`) и прямой ссылкой на Stack Overflow.
4. **Авторизация и профиль (`/auth`, `/profile`):**
   - Кнопки входа через GitHub / Google SSO.
   - Генерация постоянного Bearer-токена для Cursor / Claude Code.
   - Готовый JSON-блок конфигурации MCP для копирования в IDE.
5. **Панель администратора (`/admin`):**
   - Дашборды мониторинга: размер индекса, количество документов $N$, задержки $P_{95}$.
   - Редактор системного RAG-промпта и выбор активной LLM.

## 2. Конфигурация и переменные окружения

```bash
PORT=3000                           # Порт Web UI
GATEWAY_API_URL=http://gateway:8000 # Адрес шлюза API
```

---

## 3. Взаимодействие с Gateway

Все запросы из Web Frontend направляются на REST API Gateway (`:8000`):
- `POST /api/v1/search` — базовый поиск.
- `POST /api/v1/search/rag` — SSE-поток RAG-синтеза.
- `GET /api/v1/graph/threads` — узлы и ребра для графа.
