- **Дата проверки:** 2026-11-20
- **Ответственные:** Роль 2 (Search Core & Performance Engineer)
- **Проверяемые артефакты:**

  - Бенчмарк: `benchmark/evaluate.py`, отчёт `data/benchmark_report.json`.

### Чек-лист соответствия требованиям (AGENTS.md, п. 2 и 7):
- [x] Инвертированный индекс и Posting Lists читаются собственным кодом (`mmap` + `index_format`), готовые поисковые библиотеки не используются.
- [x] Формула BM25 и параметры соответствуют методичке ИУ5: $k_1 = 1.5 \in [1.2, 2.0]$, $b = 0.75$; пример занятия 3 воспроизведён точно (баллы $0{,}940 / 0{,}470 / 0{,}470$, tie-break по `doc_id`).
- [x] Запрос токенизируется общим токенизатором индексатора (`tokenizer_version = "1"` контролируется при загрузке); идентификаторы кода и стектрейсы не повреждаются.
- [x] Top-K реализован через Min-Heap; равные баллы — по возрастанию `doc_id`.
- [x] gRPC-сервер `:50051`: все методы `SearchService` и `GraphService` проверены по реальному каналу (14 интеграционных тестов, `make test-core`).
- [x] Индекс без `metadata.json` не загружается (`NOT_SERVING` / `FAILED_PRECONDITION`); чужие версии формата/токенизатора отвергаются; lazy reload проверен.
- [x] Изменения зафиксированы в `CHANGE_HISTORY.md` и `STATUS.md`.

### Результаты тестов и бенчмарка (2026-11-20):
- Unit-тесты (`tests/unit/`): **270 OK** (213 прежних + 57 новых: формула BM25, Top-K heap, ридер, движок, граф); 0 регрессий.
- gRPC интеграция (`make test-core`, контейнер): **57 unit + 14 gRPC OK**; баллы `Search` совпадают с независимым эталонным расчётом по файлам индекса до $10^{-9}$.
- Parity с эталоном индексатора (`tests/integration/test_core_e2e.py`, индекс построен реальным `python -m indexer corpus`): OK при $k_1 = 1.2$ и $1.5$.
- Бенчмарк золотого корпуса (`make benchmark`, 10 обычных вопросов, ловушки исключены):

| Метрика | Значение | Порог приёмки | Итог |
| :--- | :--- | :--- | :--- |
| $Recall@3$ | 0.933 | — | — |
| $Recall@5$ | 0.933 | — | — |
| $Recall@10$ | 0.967 | $\ge 0.75$ | OK |
| $MRR@10$ | 1.000 | $\ge 0.50$ | OK |
| Латентность P95 | 0.25 мс | $\le 150$ мс | OK |

Эталонные значения корпуса (занятие 3, $k_1 = 1.2$): $Recall@10 = 0.967$, $MRR = 1.000$ — при $k_1 = 1.5$ метрики **не ухудшились**.
- Живой smoke-тест: `make core-up` + gRPC-клиент — `HealthCheck: SERVING`, `GetStats` (N=30, avgdl=249.7, словарь 1569), запрос «IndexError list index out of range» возвращает релевантные треды 1/11/21, `GetThreadDetails` отдаёт `original_url`.
- Ограничение окружения: Go-тесты gateway на машине проверки не запускались (`go` не установлен); Python-часть `make test-unit` и интеграционные наборы — зелёные.

**Вывод:** часть КТ2 за Роль 2 (самописный BM25, чтение индекса, gRPC, бенчмарк) выполнена и верифицирована. Оставшаяся часть КТ2 — RAG-генерация и gRPC-клиент gateway (Роль 3).
