# Раздел Service — Архитектурные решения, источники и верификация

Данный раздел фиксирует журнал принятых архитектурных решений (ADR), нормативные источники и методические требования курса, а также протоколы проверок контрольных точек.

## Состав раздела

1. **[decisions.md](decisions.md)** — Журнал принятых решений (ADR): выбор BM25 с нуля, формат gRPC, граф связанных тредов, SSO и модель безопасности.
2. **[sources.md](sources.md)** — Официальные методические требования кафедры ИУ5 МГТУ им. Н. Э. Баумана, спецификации форматов и стандартов.
3. **[verification.md](verification.md)** — Журнал фиксации результатов прогона тестов, метрик бенчмарка и готовности контрольных точек.
