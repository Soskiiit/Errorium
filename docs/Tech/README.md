# Раздел Tech — Техническое устройство системы Errorium

Данный раздел содержит архитектурное описание, спецификации интерфейсов взаимодействия, механизмы хранения данных, инструкции по сборке и запуску, а также карту кодовой базы.

## Состав раздела

1. **[01-architecture.md](01-architecture.md)** — Компонентная структура, сетевая топология, межсервисные потоки данных (gRPC, REST, MCP, SSO).
2. **[02-running.md](02-running.md)** — Запуск системы в контейнерах, конфигурация переменных окружения, порты и системные требования.
3. **[03-data.md](03-data.md)** — Архитектура хранения: бинарный инвертированный индекс, структура Posting Lists, реляционная БД пользователей, граф связанных тредов.
4. **[04-api-and-access.md](04-api-and-access.md)** — Спецификация API: REST Gateway, SSO авторизация (OAuth2/OIDC), контракты Protobuf (gRPC) и протокол MCP.
5. **[05-verification.md](05-verification.md)** — Методика тестирования, сценарии интеграционных проверок и бенчмарки качества поиска ($Recall@k$, $MRR$).
6. **[WORKSPACE_MAP.md](WORKSPACE_MAP.md)** — Карта исходного кода репозитория и распределение зон ответственности по ролям.
