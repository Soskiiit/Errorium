## 2. Описание сервисов и зон ответственности

### 2.1. Search Engine Indexer (`services/search_engine_indexer/`, Роль 1)
- **Функция:** Офлайн-процесс обработки исходного сырого дампа Stack Overflow.
- **Особенности:**
  - Использование SAX/потокового итератора для разбора файлов `Posts.xml` (память не превышает O(1) от размера файла).
  - Алгоритм SPIMI (Single-pass in-memory indexing) с регулярным сбросом промежуточных блоков на диск и последующим многопутевым слиянием.
  - Извлечение связей между тредами (дубликаты, ссылки между постами).

### 2.2. Search Engine Core (`services/search_engine_core/`, Роль 2)
- **Функция:** Высокопроизводительный сервер ранжирования и извлечения сущностей.
- **Особенности:**
  - Реализация протокола gRPC (`:50051`).
  - Отображение файлов индекса в виртуальную память (`mmap`) для мгновенного доступа к Posting Lists.
  - Расчет оценок BM25 строго по формуле ИУ5:
    $$BM25(q, d) = \sum_{t \in q} \ln\left(1 + \frac{N - DF(t) + 0.5}{DF(t) + 0.5}\right) \cdot \frac{TF(t, d) \cdot (k_1 + 1)}{TF(t, d) + k_1 \cdot \left(1 - b + b \cdot \frac{|d|}{avgdl}\right)}$$
  - Поддержка `GraphService` для извлечения графа связанных тредов (дубликаты, ссылки).

### 2.3. Gateway & MCP Service (`services/gateway/`, Роль 3)
- **Функция:** Центральный шлюз, фасад для фронтенда и AI-агентов, RAG-оркестратор, SSO и админ-сервис.
- **Подсистемы:**
  - **Auth & SSO:** Интеграция с GitHub OAuth2 / Google OIDC / Keycloak, генерация access/refresh JWT токенов, выдача Bearer-ключей для MCP.
  - **Admin API:** Управление квотами, мониторинг состояния индексов и серверов, смена системного RAG-промпта.
  - **RAG Orchestrator:** Вызов LLM (OpenAI, Anthropic, vLLM) с формированием очищенного контекста и стримингом ответа клиенту.
  - **Remote MCP Server:** Реализация протокола MCP (HTTP/SSE) с инструментами `errorium_search_solution`, `errorium_explain_error`, `errorium_get_related_errors`.

### 2.4. Web Frontend (`services/frontend/`, Роль 4)
- **Функция:** Веб-интерфейс пользователя и администратора.
- **Стек:** Modern Single Page App (TypeScript, React/Next.js/Vite, TailwindCSS).
- **Модули:**
  - Панель поиска с удобным вводом логов и стектрейсов.
  - Просмотр решений с подсветкой синтаксиса и стримингом RAG.
  - Интерактивный граф связанных тредов (дубликаты и ссылки), встроенный прямо в результаты поиска на странице `/search`.
  - Панель администратора (`/admin`) с дашбордами и мониторингом.
