# Раздел Product — Поведение и концепция продукта Errorium

Данный раздел фиксирует функциональные рамки, сценарии пользователей, требования и логику интерфейсов системы **Errorium**.

## Состав раздела

1. **[01-context.md](01-context.md)** — Контекст, цели, бизнес-задачи и границы системы.
2. **[02-users-and-scenarios.md](02-users-and-scenarios.md)** — Ролевая модель (Инженер, Администратор, AI-ассистент) и основные сценарии (Поиск, RAG, Граф тредов, SSO, Управление).
3. **[03-requirements.md](03-requirements.md)** — Функциональные и нефункциональные требования, критерии приёмки НИРС.
4. **[04-interface-and-behavior.md](04-interface-and-behavior.md)** — Структура интерфейса, сценарии переходов экранов, модальные окна и состояния.
5. **[05-rules-and-data-meaning.md](05-rules-and-data-meaning.md)** — Смысл данных: корпус Stack Overflow, узлы и ребра графа знаний, сущности пользователей и прав.
