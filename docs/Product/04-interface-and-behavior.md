               │  Главная / Поиск (/)  │

                           │

## 2. Спецификация экранов

### Экран 1: Главная страница / Чат-экран (`/`) — Дизайн-система Errorium
- **Шапка (Header):**
  - Кнопка гамбургер-меню (слева) для вызова боковой панели на мобильных устройствах (`Chat-screen-menu-not-authorized.png`), скрыта на широких экранах (≥1024px).
  - Центрированный фирменный логотип `Errorium` (на широких экранах ≥1024px скрывается для исключения дублирования с боковой панелью).
  - Кнопка профиля / аватара (справа) с вызовом диалога аутентификации.
- **Центральная зона (Hero Empty State, `Chat-screen.png`):**
  - Глубокий темный фон `#070a13` с мягким радиальным синим свечением (аура).
  - Маскот-персонаж (фирменный парящий синий блоб с мимикой `I.I`).
  - Фоновый арт голубого огонька (`blue-fire.png`), адаптивно масштабируемый по высоте (`max-height` в `vh`); на экранах с небольшой высотой (например, внешний экран Samsung Galaxy Fold в сложенном виде или ландшафтный режим, `max-height ≤ 720px / 600px`) размер огонька пропорционально снижается, чтобы не перекрывать полезную область и не доминировать над карточкой со слоганом.
  - Фирменный слоган в моноширинном начертании:
    `Element 404. Reacts with developers` (где `404.` подсвечен акцентным красным/коралловым цветом)
    `Stack overflow. Issue overknown.` (вторая строка в приглушенном серо-голубом цвете).
  - Горизонтальный световой эллипс (световой спотлайт под слоганом).
- **Экран активного диалога сообщений (Chat-screen-dialog.png):**
  - При отправке запроса или переходе в активный чат отображается лента сообщений на фоне космического градиента со световым спотлайтом в нижней части.
  - **Сообщение пользователя (User Message):**
    - Выравнивание по правому краю (`align-self: flex-end`).
    - Пузырь сообщения (`.user-bubble`): мягкий сине-васильковый цвет `#6781db`, черный текст `#000000`, шрифт Inter (`font-family: var(--font-ui)`), скругление всех углов 18px.
    - Внутри пузыря справа от текста размещена двойная синяя галочка прочитанности/доставки (`✓✓`, `#3d529f`).
  - **Ответ ассистента (Assistant Message):**
    - Горизонтальный ряд с выравниванием по левому краю: слева аватар, справа пузырь ответа.
    - Аватар (`.assistant-avatar`): круглая иконка 38×38px с маскотом-колобком (`/message.svg`) с белой контурной окантовкой.
    - Пузырь сообщения (`.assistant-bubble`): мягкий светло-серый цвет `#c0c1c6`, черный текст `#000000`, шрифт Inter, скругление всех углов 18px, межстрочный интервал 1.45.
- **Боковая панель (Navigation Drawer / Persistent Sidebar):**
  - На мобильных устройствах (<768px) работает как всплывающий Drawer с бэкдропом и кнопкой закрытия `✕`.
  - На экранах от 768px и шире по умолчанию изначально открыта (раскрыта) в статичном лейауте слева; кнопка закрытия `✕` и затемняющий бэкдроп скрыты; заголовок `Errorium` в шапке панели служит логотипом приложения.
  - Поддерживается возможность сворачивания сайдбара на широких устройствах кнопкой с фирменной иконкой панели (`M6.5 17.5L6.5 6.5...`). Состояние (`expanded` / `collapsed`) сохраняется в Local Storage. При сворачивании сайдбар плавно скрывается влево, рабочая область расширяется на всю ширину, а в шапке отображается кнопка разворачивания с аналогичной иконкой и логотип Errorium.
  - Поле мгновенного поиска по истории `Search`.
  - Секция `Recent chats` со стрелкой сворачивания и списком типичных ошибок разработчиков с контекстным меню `⋮` (SyntaxError, IndentationError, TypeError, NameError, UnboundLocalError, KeyError). При сворачивании секции или пустом списке нижняя панель (кнопки MCP, About us, New chat, профиль/логин и настройки) остается прижатой к низу экрана (`margin-top: auto`).
  - Ссылки на раздел `MCP` и модальное окно `About us`.
  - Плавающая акцентная белая кнопка `New chat` с иконкой пера/блокнота.
  - Нижняя плашка профиля: `Log in` / `Meet new features!` и иконка настроек `⚙`.
- **Нижняя строка ввода (Prompt Bar):**
  - Капсульный контейнер с эффектом «жидкого стекла» (Liquid Glass): глубокое размытие подложки (`backdrop-filter: blur(24px) saturate(190%)`), верхний световой блик, фаски преломления и рассеянный ореол свечения.
  - Кнопка дополнительных действий `+` (вставка стектрейса, фильтры по языкам).
  - Многострочное поле ввода с автовысотой и плейсхолдером `What went wrong?`.
  - Круглая синяя кнопка отправки с сапфировым градиентом, внутренним отражением и белой стрелкой вверх `↑`.
  - Подпись: `AI can make mistakes. Check important information.`

### Экран 2: Поисковая выдача и синтез решений (`/search`, переход из чата)
- **Левая колонка:** Список результатов поиска по BM25 с отображением релевантности, количества голосов Stack Overflow, бейджей тегов и времени публикации.
- **Правая колонка (RAG Assistant):**
  - Блок потоковой генерации ответа LLM со стримингом токенов.
  - Подсветка синтаксиса кода с кнопкой «Скопировать решение».
  - Переключатель «Показать источники» (раскрывает точные фрагменты тредов, из которых сгенерирован ответ).
- **Нижняя панель (или под результатами поиска): Интерактивный граф SO-тредов**
  - Canvas с визуализацией графа связанных обсуждений Stack Overflow.
  - Цветовое кодирование: зеленый (лучший результат), желтый (Top-K), синий (дубликаты), фиолетовый (связанные ответы).
  - Наведение на узел: предпросмотр вопроса (заголовок, сниппет, наличие ответа ✅).
  - Клик по узлу: просмотр лучшего/принятого ответа.
  - Узлы содержат ссылки на оригинальные публикации.

### Экран 4: Модальное окно аутентификации (Auth-screen.png)
- Вызов окна: клик по аватару/профилю в шапке (`btn-profile`) или строке `Log in` в боковом меню (`btn-login-row`).
- Дизайн и геометрия окна (`Auth-screen.png`):
  - Модальная карточка со скруглением углов 32px на темном бэкдропе с размытием (`backdrop-filter: blur(12px)`).
  - Стилизация **Liquid Glass** карточки: оптическая полупрозрачность (`rgba(30, 48, 95, 0.45)` -> `rgba(10, 16, 32, 0.75)`), размытие подложки (`backdrop-filter: blur(32px) saturate(200%)`), тонкая кромка `1px solid rgba(255, 255, 255, 0.22)` и многослойные внутренние световые блики (`inset 0 1.5px 1.5px rgba(255, 255, 255, 0.35)`).
  - Шапка карточки: центрированный фирменный маскот Errorium (`/mascot.png`) и заголовок `Errorium` (белый жирный шрифт Inter).
  - Поля ввода `Email` и `Password`: полупрозрачные плашки Liquid Glass со скруглением 14px, контурными иконками профиля и замка, оптическим размытием и белой кромкой блика.
  - Строка параметров: фирменный зеленый чекбокс `Remember me` с белой галочкой и ссылка `Forgot password?` небесно-голубого цвета.
  - Акцентная кнопка входа `Log in`: сочно-зеленая капсула (pill, скругление 24px). При наведении (`:hover`) кнопка белеет за счет верхнего блика `inset` и светлой полупрозрачной границы, а также излучает эффектное красное неоновое свечение (`rgba(252, 63, 29, 0.25)`), идентично эффекту кнопки входа через Яндекс ID.
  - Разделитель `or` с тонкими полупрозрачными линиями по бокам.
  - Кнопка SSO-авторизации: `Continue with Yandex ID` в стиле Liquid Glass с аутентичным векторным логотипом Яндекс ID (`fill="#FC3F1D" fill-opacity="0.65"`, точные векторные кривые литеры `Y`).
  - Подвал карточки: навигационная ссылка `New here? Sign up`.
  - **Адаптивность для мобильных устройств (смартфоны ≤480px / малая высота):**
    - Компактная геометрия карточки: `max-width: 330px`, уменьшенные внутренние отступы (`padding: 24px 20px 20px 20px`), скругление углов `26px`.
    - Пропорциональное уменьшение элементов: маскот `58px`, заголовок `1.35rem`, высота полей ввода и кнопок `44px` (вместо `50px`/`48px`), уменьшенные межстрочные интервалы для идеального отображения на экранах телефонов без громоздкости.
- Поведение:
  - Авторизация по логину/паролю или через Yandex ID SSO.
  - Закрытие окна по клику на затемняющий бэкдроп, крестик или клавишу Escape.
  - При успешном входе: обновление отображаемого имени/почты в интерфейсе и активация MCP-токенов.

### Экран 5: Профиль и интеграция с AI-ассистентами (`/profile`)
- Данные пользователя, история поисковых запросов.
- Секция **«Model Context Protocol (MCP)»**:
  - Генерация персонального Bearer-токена.
  - Готовый JSON-сниппет конфигурации для вставки в `~/.cursor/mcp.json` или `claude_desktop_config.json`:
    ```json
    {
      "mcpServers": {
        "errorium": {
          "url": "https://errorium.ru/sse",
          "headers": {
            "Authorization": "Bearer <YOUR_TOKEN>"
          }
        }
      }
    }
    ```

### Экран 6: Панель администратора (`/admin`)
- Доступ только для пользователей с ролью `admin`.
- **Вкладка «Индекс и Движок»:** размер индекса, количество документов $N$, статус сборки индекса, кнопка «Переиндексировать дамп».
- **Вкладка «RAG & LLM»:** выбор активного провайдера (OpenAI, Claude, Local), редактор системного промпта с версионированием, установка max_tokens и temperature.
- **Вкладка «Пользователи и безопасность»:** список зарегистрированных пользователей, роли, принудительный отзыв токенов.
- **Вкладка «Аналитика»:** графики $P_{95}$ задержки, статистика популярных ошибок, отчет по качеству ответов.
