# 01-context.md — Цель, границы и концепция продукта

## 1. Назначение системы

**Errorium** — это интеллектуальная платформа поиска программных ошибок, анализа аварийных логов/стектрейсов и синтеза решений на основе дампа базы знаний Stack Overflow (~100 ГБ).

Система закрывает ключевую проблему разработчиков: медленный, неточный и фрагментированный ручной поиск решений при отладке программного обеспечения.

## 2. Границы системы (System Boundaries)

### Входит в область действия (In-Scope):
1. **Специализированный поисковый движок:**
   - Потоковая индексация архивов Stack Overflow без использования готовых поисковых движков (Elasticsearch/Lucene).
   - Токенизация с сохранением структуры стектрейсов, типов исключений и синтаксиса языков программирования.
   - Ранжирование кандидатов по кастомной формуле BM25 с фильтрацией по тегам.
2. **RAG-оркестрация (Retrieval-Augmented Generation):**
   - Формирование релевантного контекста из Top-K документов.
   - Синтез структурированного решения (причина ошибки, исправленный код, рекомендации).
3. **Model Context Protocol (Remote MCP Server):**
   - Предоставление стандартизированных инструментов поиска для внешних AI-агентов (Cursor, Claude Code, Windsurf) по протоколу MCP.
4. **Интерактивный граф связанных SO-тредов:**
   - Построение графа взаимосвязей между найденными вопросами и ответами Stack Overflow, а не абстрактными сущностями.
   - Интерактивная визуализация графа (отображение дубликатов и связанных дискуссий) напрямую на странице поиска.
5. **Идентификация, доступ и безопасность:**
   - Единая точка входа (SSO) через корпоративные/публичные IdP (GitHub, Google, OIDC/OAuth2).
   - Ролевая модель доступа (RBAC: Гость, Авторизованный разработчик, Администратор).
   - Панель администратора (Admin Dashboard) для управления парсингом, индексами, промптами RAG и квотами.

### Не входит в область действия (Out-of-Scope):
- Автоматическое применение патчей в git-репозиторий пользователя без его подтверждения.
- Мониторинг логов продакшн-систем в реальном времени (Errorium не является APM/Sentry аналогом, а выступает базой знаний и RAG-поисковиком).
- Парсинг сторонних сайтов на лету (индексируется только предварительно подготовленный корпус Stack Overflow).
